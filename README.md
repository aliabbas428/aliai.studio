# AliAI Studio

Claude-style AI chat UI running on Cloudflare Workers + Workers AI.

## Important
This project is **not Claude Pro** and does not provide or unlock a paid Anthropic/Claude subscription. It is an independent AI interface.

## Deploy
1. Connect this repository to Cloudflare Workers.
2. Deploy with Wrangler.
3. The Worker AI binding is named `AI`.
4. The model can be changed with `AI_MODEL`.

No Anthropic API key is placed in the browser.
